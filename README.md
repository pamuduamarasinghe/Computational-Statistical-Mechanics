# Computational Statistical Mechanics
From Statistics to Nature of the Universe

A collection of computational physics simulations and numerical methods developed as part of the **Computational Statistical Mechanics** course. This repository contains Python implementations of Monte Carlo methods, Markov Chain Monte Carlo (MCMC), molecular simulations, statistical distributions, and quantum statistical mechanics.

---

## Course Topics

- Monte Carlo Integration
- Random Number Generation
- Inverse Transform Sampling
- Metropolis Algorithm
- Markov Chain Monte Carlo (MCMC)
- Hard Disk Monte Carlo Simulations
- Molecular Dynamics
- Maxwell–Boltzmann Distribution
- Harmonic Oscillator Density Matrix
- Statistical Ensembles
- Partition Functions
- Quantum Statistical Mechanics
